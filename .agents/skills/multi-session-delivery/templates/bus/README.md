# Session message bus

Durable copy of the messages between the sessions. Copy this folder to `<workspace>/.agents/bus/` and list the session names in `lanes.txt`, one per line (`pm` is always accepted). `lanes.txt`, `.agents/pm/lanes.json` and the lane table in the rules must name the same sessions.

- **Send:** `bash send.sh <to> <from> "<one line>"` appends `<ISO time> | from <sender> | <message>` to `inbox-<to>.md` (newlines become spaces), then send the live message.
- **Receive:** `bash read.sh <me>` prints the lines after your read mark (`read-mark-<me>.txt`, 0 when missing) and leaves the mark where it is. Act on each line, then acknowledge with the command it printed: `bash read.sh <me> --ack <line>` moves the mark to that line. Delivery is at least once: a session that stops before acknowledging sees the same lines again, so a line that arrives while you work is never skipped. If `archive.sh` ran between the read and the acknowledgement, read again first: the line numbers shifted.
- **Never** edit or delete lines by hand. Each week the coordinator runs `bash archive.sh 7`: under the bus lock it moves lines that are older than 7 days and already acknowledged to `archive/` and shifts the read mark. Unacknowledged lines always stay.
- All three scripts share one lock (`.lock`, a file created with an exclusive open, holding the owner's pid, start time and host). It is released on exit, interrupt and termination. A lock left by a killed script is taken over by the next script once its owner's pid is gone, or once it is older than `BUS_LOCK_STALE` seconds (default 60); nothing is removed by hand. A script waits `BUS_LOCK_TRIES` tenths of a second (default 100) and then exits 3. Session names are lowercase letters, digits and hyphens. A lock whose owner was never written (a script killed between creating it and writing it) is aged in whole minutes, so it is taken over only after about 2 minutes with the default; until then senders exit 3.
- **No secrets** (tokens, keys, passwords, personal data) in any line.
- Renaming a session: add the new name to `lanes.txt`, test `send.sh` and `read.sh` with it, then update the rules files in the same step.
