# Handoff Template

```markdown
# Handoff: <task> (<repo>, <date time>)

## Goal
<one sentence: what done looks like>

## Current State (verified)
- Working + tested: <list>
- Last check: `<command>` → <status line>
- Branch / commit: `<branch>` @ `<sha>`; dirty files: <list or none>

## Next Steps
1. <smallest next action, with file:line>
2. ...

## Blockers / Uncertainties
- <what stopped execution, what needs the user>

## Open Hypotheses (believed, not verified)
- <theory> → <how to check>

## Files Touched
- `path` — <why>

## Existing Artifacts (read these, do not redo)
- <spec / plan / ADR / issue / PR path or URL>

## Suggested Skills
- `<skill>` for <reason>; `<subagent>` for <reason>

## Do Not
- <decisions already made that must not be reopened; cite log entry>
```

Keep under ~60 lines. Redact secrets and personal data.
