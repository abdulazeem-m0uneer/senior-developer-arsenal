# Senior Developer Arsenal (Lite)

Senior engineering skills and subagents for AI coding agents: investigation, code review, testing, security, databases, APIs, frontend, mobile, DevOps and more. Each skill is a step-by-step runbook with a verification protocol, so the agent proves its work instead of claiming it.

This is the text-only edition for the plugin directory. It has no hooks and no scripts. The full arsenal adds guards that block risky commands and unproven "done" claims, a lessons ledger that turns repeated mistakes into rules, and the ship, CI and multi-session skills. Install the full edition from https://github.com/abdulazeem-m0uneer/senior-developer-arsenal.
